# Anime Sama — Android TV

Une version Android TV de l'interface Anime Sama.

## Le projet

Cette édition possède son propre projet Android. Elle vise une navigation fluide à la télécommande, avec accès aux séries, aux épisodes et à la reprise de lecture.

L'application Android est indépendante de l'édition LG.

## Matériel

Android TV

## Installation

Installation prévue par APK, avec une procédure courte d'installation manuelle.

## État

APK public non disponible. La compilation propre, les permissions et les tests sur appareil vierge restent à vérifier.

Le dépôt sert pour l'instant à documenter le projet. Il ne contient pas encore de version à installer. Les premiers fichiers de code seront ajoutés après la vérification des informations privées et des droits de redistribution.

## Signaler un problème

Utiliser les issues GitHub en précisant l'appareil, le firmware et la manière de reproduire le problème. Ne pas publier de jeton d'appairage ou de données personnelles.
