# Configuration reseau

L'APK est independant de la version LG. Les preferences, l'historique et les services facultatifs doivent etre configurables.

Le moteur actuel contient encore des adresses de fournisseurs. Il ne doit pas etre diffuse tel quel. Le client public utilisera une API de catalogue distincte et des connecteurs autorises.

Aucun jeton, adresse IP personnelle, cache utilisateur ou identifiant de machine ne doit se retrouver dans le depot ou le paquet. Les erreurs de connexion doivent etre gerees sans bloquer la navigation.
